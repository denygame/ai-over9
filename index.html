01 · NIGHT SHIFT

What a night with AI Over9 looks like

You set the work and walk away. AI Over9 keeps watch, wakes you only when it matters, and turns the lights off when it is done.

  1. 22:10

    You leave

    Two sessions are working. The Mac stays awake for them — and only for them.

  2. 01:42

    One needs you

    Codex wants to run a command. Your phone shows the exact command with Allow / Deny.

  3. 03:15

    A limit resets

    The usage limit is back. The waiting session gets “continue” and carries on by itself.

  4. 06:30

    All done, lights off

    Every agent has finished. A short countdown, then the Mac sleeps. The answers wait in Telegram.

05 · Safety

Guard rails you can trust overnight

Letting agents work alone needs limits. These are built in and switched on only when you choose.

🛡️

Command shield

Deleting files or losing work in Git is refused before it runs. Pushing and publishing always ask first. Add your own rules.

🔐

Your code for risky commands

From Telegram, risky commands need Allow, a fresh authenticator code and one more confirmation of the exact command.

🕒

Commit often

An optional skill for Claude Code and Codex commits every finished step locally — and sets up Git where there is none.

♻️

Keeps running

If the app is killed or crashes, macOS opens it again within seconds, and it checks every minute that the agents still report to it.

🏠

Local first

No account, no analytics — just an anonymous daily install count (a random id, app and system version, chip type). Agent content leaves the computer only if you turn it on — and only to your own Telegram chat.

🔐

Two factors to act

Writing, approving and starting sessions need the Owner and a code from your authenticator app. A stolen Telegram account is not enough.

🛡️

Nothing bypassed

The agents' own permission rules always apply. The bot never runs a shell command. Unanswered prompts fall back to the computer.

🔑

Secrets stay secret

Tokens live in the Keychain (Credential Manager / keyring on Windows and Linux) — never in files, logs or backups.

09 · FAQ

Questions

Is it free?

Yes. No ads, no account. You can buy the author a coffee from the app if you like.

Does my code leave my computer?

Not unless you turn on sharing agent answers — and then only to your own Telegram bot chat. Hooks pass event metadata; token counts are read as numbers only.

Can someone with my Telegram control my agents?

No. Writing to agents, approving prompts and starting sessions need a code from your authenticator app, and only the Owner can do it.

What if I don't answer a permission prompt?

Nothing is approved. After a few minutes the agent asks on the computer exactly as it would without AI Over9.

Which agents are supported?

Claude Code (terminal, VS Code, desktop app) and Codex (CLI, VS Code, ChatGPT app) with full control. Cursor Agent, Gemini CLI, Aider, OpenCode and more are detected from their process.

Why does macOS warn the first time?

The app is signed by its author but not notarized by Apple yet. Right-click › Open once, or install with Homebrew.
